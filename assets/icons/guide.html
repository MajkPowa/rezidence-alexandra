Rám a práh.

36 vlastních ikon pro jednu adresu. Pět balkonových pásů nad vstupním podlažím, dvě fasádní pole, svislé lamely a otevřený roh přecházejí z architektury domu do navigace i detailů bytů.

Velké architektonické kresby používají plátno 64 × 64. Ovládací ikony používají 24 × 24. Drobné náhledy níže jsou skutečných 24 px; architektonické linky jsou v této velikosti zesílené na 3,2 jednotky.

Zapojení

Stejný originál lze použít jako externí symbol nebo samostatný SVG soubor. Pro barevné propojení s textem je vhodný externí symbol. Identifikátory jsou bez prefixu.

<svg class="alex-icon" viewBox="0 0 64 64" aria-hidden="true">
  <use href="assets/icons/alexandra.svg#residence"></use>
</svg>

<svg class="alex-icon" viewBox="0 0 24 24" aria-hidden="true">
  <use href="assets/icons/alexandra.svg#arrow-up-right"></use>
</svg>
.alex-icon { color: #253a32; --icon-accent: #a77950; }
.art-at-32 { --icon-stroke: 2.8; }
.art-at-24 { --icon-stroke: 3.2; }

Ikona vedle textového popisku má aria-hidden="true". Samostatná významová ikona potřebuje role="img" a vlastní přístupný název na nadřazeném SVG. Tlačítko pojmenujte na samotném tlačítku. Titulky uvnitř externího spritu nejsou spolehlivým přístupným názvem.

Tento lokální proof obsahuje kresby přímo. V aplikaci se externí use načítá přes stejný HTTP(S) původ. Při file:// mohou prohlížeče externí use blokovat. Samostatný SVG vložený jako img nedědí barvu okolního textu.
